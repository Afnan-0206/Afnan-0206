## Projects

### [BizPilot AI](https://github.com/Afnan-0206/BizPilot)

Multi-agent AI administrative assistant for small-business workflows.

- **Stack:** React, Node.js, Express, Google Gemini API
- **Architecture:** Pipeline-based workflow for parsing customer inquiries, referencing pricing information, generating quotes/invoices, and running an internal QA validation pass.
- **Live Demo:** https://biz-pilot.vercel.app

### [Recoup](https://github.com/Afnan-0206/recoup)

Failed-payment triage and revenue-recovery dashboard built for the Razorpay AI Buildathon.

- **Stack:** React, Vite, Node.js, SQLite, Anthropic Claude API
- **Architecture:** Classifies failed payment events, determines retry windows, and generates customer-recovery outreach based on payment failure conditions.

### [NammaFix AI](https://github.com/Afnan-0206/nammafix-ai)

Civic infrastructure reporting platform for municipal grievance triage.

- **Stack:** React, Vite, Three.js, Tailwind CSS
- **Architecture:** Interactive application for reporting civic defects such as potholes, water leaks, and sanitation issues, with severity scoring, ward-based routing, and a Three.js-based 3D infrastructure viewer.

### [AutoFix AI](https://github.com/Afnan-0206/autofix-ai-incidents)

AI-assisted DevOps incident triage system for application errors.

- **Stack:** React, Node.js, Express, LLM API integration
- **Architecture:** Processes application error logs and stack traces, investigates possible root causes, proposes remediation actions, and supports incident-response workflows.
